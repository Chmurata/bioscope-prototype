# Reference screenshots

Captures from the live Bioscope+ app, used as the visual and interaction benchmark for the four Play Journey tasks.

```
player/        — long-form player: landscape, controls, trailer, any portrait behaviour
subscription/  — subscribe / pack / checkout pages as they ship today
```

Each subfolder carries a `NOTES.md` recording what each capture shows and what it settles — the point is to fix decisions (layout, control placement, CTA treatment) against something real rather than inventing them.

Naming: `NN-short-description.png`, numbered in flow order.
